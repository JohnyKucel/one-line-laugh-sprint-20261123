A one-line joke about everyday life: a phone dies in the middle of an argument, and its owner finishes the argument out loud, alone — and still loses.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/laugh-output python3 main.py
```

Writes one 95-character line to `entry.txt` in the output directory (or `output/` when `MAKEFUN_OUTPUT_DIR` is unset). Python 3.13, standard library only, deterministic — no network, no randomness, no clock.
